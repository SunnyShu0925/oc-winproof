# Windows Native Proof for openclaw PR #172869

This repo runs a GitHub Actions Windows runner to produce native Windows proof
for [openclaw/openclaw#172869](https://github.com/openclaw/openclaw/pull/172869).

## Usage

1. Go to Actions → "Windows Native Proof (PR #172869)" → Run workflow
2. Enter the PR branch name (default: `fix/cron-cwd-trim-201`)
3. Download the `windows-proof-output` artifact
